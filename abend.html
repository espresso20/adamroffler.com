Operator Terminal // Active

ABEND

A Cold-War Terminal Simulator

Situation Report

You play on a set of terminals inside a bunker system that seems to go on forever. You explore it by playing a text adventure, finding resources that let you build out your computer system, which lets you do more, faster, which reaches further into the bunker, which turns on more of the system.

The tech tree, the interface and the fiction are the same object. Every upgrade is a new command you can type. Most games have to fake that connection. This one gets it from the premise.
