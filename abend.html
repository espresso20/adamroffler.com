ABEND

A Cold-War Terminal Simulator

A bunker that goes on forever. You explore it by typing.

Back to Projects

Situation Report

You work a set of terminals inside a bunker system that seems to go on forever. The lights are on in the room you are in. Everything past that is dark, and the only way to find out what is down there is to type.

What you find lets you build out your computer system. A better system reaches further into the bunker, and reaching further turns on more of the system. That loop is the game.

Game Systems

The tech tree, the interface and the fiction are the same object.

Every upgrade you find is a new command you can type. Not a menu item that lights up — a word that starts working. Most games have to fake the connection between a progression system and the thing you actually do all day. This one gets it from the premise, and protecting that is the constraint every other decision answers to.

The Interface

The whole game is a terminal. Panels declare a tree of regions and the display renders it; there is no HUD layered over the top and no second screen to manage.

The CRT treatment is not a filter applied to a game. It is the thing you are looking at.

Status

Early, and honest about it. The command registry, the panel and region layout and the headless core are in. There is a terminal you can type into.

An earlier version of ABEND was a civilization idler spanning 22 ages. That design is retired. This is a different game wearing the same name.

Under the Hood

Godot 4 and GDScript. The game logic runs headless and Godot is a display layer only, so the core is testable without the editor and every command carries a golden transcript that gets diffed on each change.

Five guardrails run on every commit: no source file over 300 lines, one file per command found by a registry with no dispatch table anywhere, the core runs headless, every command has a transcript, and the documentation stays smaller than the game.
